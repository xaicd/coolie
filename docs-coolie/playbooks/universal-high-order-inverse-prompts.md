# Coolie 平台高阶反向思维通用提示词资产库 (Universal High-Order Inverse Prompts)

> **制定级别**: 平台级高阶反向思维 AI Harness 标准库 (波次 wave358)  
> **核心使命**: 沉淀四大合一最高审视视角（交付公司负责人 × Palantir 体系 × OpenAI/Palantir FDE × 顶级产品总监），为下游重型业务开发模板（如 `ruoyi-all-next`）与本工程所有 AI 助手提供实战级、非空泛的工程反向穿透提示词资产。

---

## 一、 四大合一最高审视视角

当面对简短输入时，AI 严禁立即顺拐输出代码或方案，必须自动佩戴四大战袍反向穿透：
1. **新型软件交付公司负责人**：算交付人效比、客户零培训上手、拒绝系统空转两张皮；
2. **Palantir 体系**：业务双核驱动 (Object + Action)，消灭死报表与死图谱，三元力量协同（Echo 价值定义、Delta 现场跑通、Dev 反向传播）；
3. **OpenAI / Palantir FDE**：深入一线业务现场、真机真实环境四态验证、敢于彻底删除错误功能；
4. **顶级产品总监**：极简使用主义、两字操作铁律、零重复入口、零冗余配置。

## 二、 五大核心通用反向提示词模版

### 模版 1：【反向穿透·重型业务实体溯源与模型减法】
- **适用场景**：建表、加字段、加模块、设计数据流。
- **核心逻辑**：
  1. **查重与收敛**：现有实体中是否已有同构承载？是新独立实体还是现有实体的状态机演进？
  2. **动词契约化**：先定 ActionType 与状态变迁，严禁散落无序的底层 CRUD。
  3. **模型减法**：证明字段无法通过计算得出，杜绝为了临时报表滥建宽表。

### 模版 2：【反向穿透·企业级严格多租户与组织权限防线】
- **适用场景**：写接口、查数据、数据导出、组织权限流转。
- **核心逻辑**：
  1. **物理租户强制注入**：SQL / ORM 强制携带上下文 `tenant_id`，严禁相信前端传入的租户参数。
  2. **数据范围物理拦截**：本人/本部门/下级等权限必须在 Repository 入口处拦截，严禁只在前端做按钮隐藏。
  3. **跨域 Seam 契约**：跨域必须走公开 Facade 或 RPC，严禁越界直接 import 他域内部 Service/DAO。

### 模版 3：【反向穿透·现场人机工效与极简两字交互】
- **适用场景**：做页面、做大盘、移动原生端交互、复杂表单。
- **核心逻辑**：
  1. **现场人机推演**：6 寸手机屏坚决不画全景网状图，只画局部 1-Hop 因果卡片流；防键盘遮挡，弹窗加独占层。
  2. **两字按钮契约**：主动作强制收敛为纯 2 汉字（【创建】、【查看】、【审批】、【驳回】、【发布】），零技术泄露。
  3. **四态闭环**：完整覆盖加载态 (Loading)、正常态 (Data)、空数据态 (Empty)、异常重试态 (Error)。

### 模版 4：【反向穿透·因果归因与防退化单测存证】
- **适用场景**：修 bug、报错排查、异常修复、单测编写。
- **核心逻辑**：
  1. **5-Why 溯源**：报错是表象，破坏的核心状态机契约是什么？
  2. **拒绝打补丁**：严禁局部 `try-catch` 吞异常或加布尔开关，能删代码解决绝不贴膏药。
  3. **SpaceX 级防退化测试**：严禁空壳 Mock，必须针对破坏边界编写强断言的真值防退化用例，固化调用证据。

### 模版 5：【反向穿透·重型插件演进与平台反向传播】
- **适用场景**：模块解耦、插件化扩展、抽取公共底层能力、重构底座。
- **核心逻辑**：
  1. **特例与通用解耦**：区分一线特例需求 (Delta) 与平台通用能力 (Dev)，禁止业务特例污染核心契约。
  2. **Everything is a Plugin**：业务独立可拔插，挂掉不影响底座宿主。
  3. **Human Backpropagation**：将一线填坑经验沉淀为工程守卫（如 `guard-high-order-invariants.cjs`）与 CLI 脚手架，规模化复用。
