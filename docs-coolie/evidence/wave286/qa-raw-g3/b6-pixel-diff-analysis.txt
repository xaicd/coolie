B6 吸顶「不透行」像素级差分检验 (focus-probe.cjs 产物 b6-band-0/1.png, PIL 分析)
================================================================================
采样: group 视图, 同一节头 (项目-1, key d67483cc…) 在两个不同滚动位置吸附:
  band-0: scrollY=1034, band-1: scrollY=1084 (节头下方底层行相差 50px)
  节头几何两处一致: topDelta=0 (贴顶), 底 38×1063px, 计算样式 alpha=oklch(1 0 0) (不透明), z=10
原理: 若节头半透 (透行), 底层滚过的不同行文字/边框会在节头带内留下大幅像素差;
      不透节头则两带应逐像素一致 (除 AA/边缘亚像素抖动)。
PIL ImageChops.difference 结果:
  diff bbox = (0, 31, 1063, 38)  → 差异仅集中在带底部 7px 条带
  各通道 max delta = (5, 5, 5)/255 ≈ 2% 幅度 → AA/描边级别, 非文字级 (文字渗入会产生 ~200 级差)
  带内其余 31px 逐像素全同 (bbox 起于 y=31)
结论: 无透行。吸附机制 (贴顶 0px / 不透明底色 / z=10 压行) 成立。
附注: 走查 DOM 几何探针旧谓词 (行矩形 bottom > mainTop+8 计为「透行」) 会把被不透明节头
      遮蔽的几何跨行误报为透行 → 已改为「露出节头带下沿才算」谓词, 并以本像素差分为准。
