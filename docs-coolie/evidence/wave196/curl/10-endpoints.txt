## E. fix 后预期 (deploy 0.6.5 server 后)

§A 第 5 行 `/api/admin/users` 期望从 403 → 200 (新加 bypass 让 `api_key` source +
`isInstanceAdmin=true` 短路 `access.assertInstanceAdmin` 的 DB membership 查询, 跟
`authz.assertInstanceAdmin` 对齐).

部署后重跑本文件 §A, 期望 10/10 端点全 200. 重跑命令:

```sh
ssh -o BatchMode=yes tc-coolie-claw "
  KEY=\$(sudo awk -F= '/^PAPERCLIP_API_KEY=/{print \$2}' /etc/coolie/secrets.env)
  for ep in /api/health /api/companies /api/skills/available /api/skills/index \
            /api/admin/users /api/board-api-keys /api/cli-auth/me \
            /api/companies/b0080331-d2b6-4e44-bb7f-61d2e288c59a \
            /api/companies/b0080331-d2b6-4e44-bb7f-61d2e288c59a/agents \
            /api/companies/b0080331-d2b6-4e44-bb7f-61d2e288c59a/dashboard; do
    code=\$(curl -s -o /dev/null -w '%{http_code}' -H \"x-paperclip-api-key: \$KEY\" http://127.0.0.1:3100\$ep)
    printf '  %-70s %s\\n' \"\$ep\" \"\$code\"
  done
"
```
