## T-2. POST /api/agents/:id/keys with BOGUS agent token — expect 403 (not 401)
```
HTTP 403
{"error":"Board access required"}
```
403 (not 401) is intentional: requireRole runs BEFORE agent-key verification,
so an attacker cannot tell whether their bogus token would have been valid
if the role check had passed. Closes a token-existence oracle.

## T-3. POST /api/agents/:id/keys with REAL agent token — expect 403
```
HTTP 403
{"error":"Board access required"}
```
Even with a valid agent token, the endpoint refuses because board-only
operations (agent-key minting) MUST come from a board actor. requireRole(board)
is the thin wrapper over the existing assertBoard — the route handler no longer
needs to import the symbol, just declare the role string.
