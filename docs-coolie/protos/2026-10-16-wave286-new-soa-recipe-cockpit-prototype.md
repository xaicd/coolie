## 1. 原型设计总纲与人机工程学原则 (Ergonomic Principles)

1. **6 寸屏单手大拇指盲操法则 (Thumb Zone Ergonomics)**：
   - 手机屏幕上半部分用于信息呈现（态势横幅、配方简介、变更 Diff）；
   - 所有关键操作手柄下沉至屏幕底部 1/3（大拇指舒适扇形弧度内）；
   - 彻底消灭多层模态弹窗堆叠，采用“就地局部一跳抽屉 (In-Place 1-Hop Sheet)”，点击外部阴影或下拉手柄平滑收起。

2. **严格两字操作动词铁律 (Two-Character Action Invariant)**：
   - 按钮文案严格限制为 2 个汉字，消灭口语化与冗长句式：
     * `装配` (实例化并装配场景配方)
     * `试跑` (Dry-run 运行测试)
     * `预检` (触发 2PC Phase 1: Prepare 预检)
     * `核准` (确认 2PC Phase 2: Commit 提交)
     * `驳回` (中止 2PC 流程并安全回退)
     * `检视` (查看实体详情与字段)
     * `溯源` (穿透查看因果血缘链条)

3. **消灭全景迷宫拓扑，采用「局部一跳因果链条 (Local 1-Hop Provenance)」**：
   - 手机端与桌面端坚决不画庞大复杂的全景网状图；
   - 任何实体卡片仅聚焦三元组关系：“前驱 (From) ➔ 当前态 (Current) ➔ 后继 (To)”；
   - 降低大脑认知负载，实现高管 0 培训一眼看懂。

4. **黄金对称 5 槽位底栏 (Golden Symmetrical 5-Slot Dock)**：
   - 固化为：`[ 汇览 ]   [ 任务 ]   [  ＋  ]   [ 工坊 ]   [ 资产● ]`；
   - 中间加号居中高亮，左右两翼严格各 2 个 Tab 对称，杜绝任何偏心漂移。

## 3. 双端交互状态机与事件映射表

| 用户动作 | 触发事件 | 界面状态流转 | 前端组件 / 路由 |
| :--- | :--- | :--- | :--- |
| 点击配方卡片【装配】 | `RECIPE_ASSEMBLE` | 实例化配方 DAG，生成待办 WBS 树形任务草案 | `RecipeCatalogStrip.tsx` |
| 点击配方卡片【试跑】 | `RECIPE_DRY_RUN` | 执行配方静态语法与 2PC 阶段检查，输出检查结果 | `WorkflowRunnerModal.tsx` |
| 触发高危 Action【预检】 | `ACTION_PREPARE` | 弹出 2PC 预检抽屉，展示影响实体数与确认令牌 | `TwoPhaseCommitSheet.tsx` |
| 掌柜在抽屉点击【核准】 | `ACTION_COMMIT` | 携带令牌与幂等键调用底层服务，状态转为已生效 | `TwoPhaseCommitSheet.tsx` |
| 掌柜在抽屉点击【驳回】 | `ACTION_ABORT` | 作废令牌，释放资源，抽屉收起并提示安全回退 | `TwoPhaseCommitSheet.tsx` |
| 点击实体卡片【检视】 | `OBJECT_INSPECT` | 就地滑出 360 度局部一跳抽屉，展示属性与规则 | `ObjectProvenanceSheet.tsx` |
