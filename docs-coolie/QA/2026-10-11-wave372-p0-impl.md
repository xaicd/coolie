## 3. 核心契约与底层架构演进

### 3.1 统一工作项与日期分组类型
在 `clients/expo/src/screens/InboxScreen.tsx` 中固化统一契约：
```typescript
export type DateSectionTitle = "TODAY" | "YESTERDAY" | "EARLIER";

export interface DateSection<T> {
  title: DateSectionTitle;
  data: T[];
}

export type MobileInboxWorkItem =
  | { kind: "issue"; id: string; issue: Issue; timestamp: number }
  | { kind: "approval"; id: string; approval: InboxApprovalItem; timestamp: number }
  | { kind: "failed_run"; id: string; run: InboxFailureItem; timestamp: number }
  | { kind: "mention"; id: string; mention: InboxMentionItem; timestamp: number };
```

### 3.2 客户端 API 契约扩充 (`@coolie/api-client`)
在 `clients/api-client/src/client.ts` 与 `types.ts` 中补齐端点映射：
- `listIssues`: 扩展支持 `touchedByUserId`, `inboxArchivedByUserId`, `unreadForUserId`, `assigneeUserId` 查询参数；
- `markIssueRead`: `POST /api/issues/:id/read` 单条已读持久化；
- `markIssueUnread`: `DELETE /api/issues/:id/read` 单条取消已读；
- `Issue`: 增加 `isUnreadForMe?: boolean;` 与 `lastActivityAt?: string | Date;` 强类型定义。
