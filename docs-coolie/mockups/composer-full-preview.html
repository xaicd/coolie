📋 设计说明 (给老板预览)

  • 品牌色: 紫蓝 #5E6AD2 + 近黑背景 + Linear 设计风 (跟现有 0.5.13 完全一致)
  • 标题栏: 「XROA › New task」+ 全屏 ↗ + ✕ 关闭 — 跟 Coolie Web NewTaskDialog 同款
  • 标题输入: 大字号 (20px) 突出重点
  • For/Assignee/Project 行: 三列 pill-select, ⋯ 更多可展开
  • 描述: textarea 自动撑高, 支持 Markdown (切换在 ⋯ 菜单)
  • 状态/附件/模式/更多: 4 chip 横向排列
  • ⋯ 菜单: 标签/截止日期/信任策略/Markdown 切换/高级设置
  • 优先级: 4 chip (低/中/高/紧急) — 跟 Coolie Web 一致
  • 底部双按钮: Discard Draft (灰) + Create Task (紫蓝实心)
  • 底部 5 tab: 汇览/任务/[+]/员工/收件箱 (wave22 修了浮层不挡)
  • 状态行 ⋯ 菜单: 点 ⋯ 展开/收起二级菜单

🎯 关键设计决策

  • 不复用 NewTaskDialog JSX: React-DOM 不能在 RN 跑, 只复用 API 契约 (POST /api/issues 字段)
  • ComposeOverlay 让出 TabBar: bottom: 76px (跟 wave22 一致)
  • 状态切换: chip 形式而非下拉 (跟 Coolie Web 同款), 选中态紫蓝 accent
  • 优先级 4 选: 用 dot 色 + 文字 (低=灰/中=橙/高=红/紧急=红)
  • 中文化: 标题栏保留英文「New task」(跟 Coolie Web 同款), 其他字段中文
