# Coolie 装机自检 SOP（3 步）+ 防装错指南

> 老板 2026-09-21 装 0.5.1 后看到「开发调试环境」= 实际装的是 0.5.0 (304) 老 APK。
> 根因：在 weixin 对话里点链接下载，微信下载管理可能缓存/分发老 APK。

---

## 1. 装机前必做（自检）

```
❌ 不要做:
 · 在 weixin 对话里点链接下载 APK
 · 用浏览器「下载历史」里以前的 coolie-release.apk
 · 用任何「下载管理器」应用

✅ 必须做:
 · 用浏览器「无痕模式」打开下载链接
 · 或在系统浏览器「清除浏览数据」后再打开
```

## 2. 装机后必看 4 件事

打开 App 后，**汇览页**顶部状态：

| 看到的 | 含义 | 下一步 |
|---|---|---|
| ✅ 无「提示」弹窗 | APK 是 OTA enabled 版 | 继续 §3 |
| ❌ 「当前运行在开发调试环境，OTA 热更新未启用」| **装错 APK 了**（0.5.0 老 APK）| 卸了重装 §4 |
| ❌ App 进不去 / 白屏 / 启动崩 | 可能签名不一致 | 卸了重装 §4 |

设置 → 关于 → 版本号（确认）：

| 版本号 | 含义 |
|---|---|
| 0.5.2 (502) | ✅ 最新；首屏应弹「装机自检」说明屏 |
| 0.5.1 (501) | ✅ 装对了（但没有装机自检屏） |
| 0.5.0 (500) | ✅ 是 0.5.0 真版本（OTA patch 之后应该看到 Workspace） |
| 0.5.0 (304) | ❌ OTA 修复前的版本，重装 |
| 0.3.x | ❌ 老的太多，重装 |

## 3. 装机后 4 Tab 验证

```
底部 → "工坊" tab → 右上角 [Workspace] 按钮
↓
弹 Modal → 看到 4 Tab: 对话 / 预览 / 文件 / 终端
```

如果「工坊」tab 进去是空的对话流 = 没登录 = 先注册 / 登录账号。

## 4. 装错 APK 强制卸载 + 重装

```
1. 设置 → 应用 → Coolie → 卸载
2. 浏览器「无痕模式」(Chrome: 新建无痕标签页)
3. 地址栏输入:
 https://dls.xrobinai.cn/coolie/app/0.5.2/coolie-release.apk
4. 下载 (74 MB)
5. 下载完点开 APK → 装
6. 打开 App → 首屏应弹「Coolie 0.5.2 已就绪」装机自检屏 → 版本号 = 0.5.2
```
