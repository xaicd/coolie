## 2. 渲染层映射（重要 — 别用错 API）

| Expo 用的 | H5 改用 |
|---|---|
| `react-native-webview` `<WebView>` | `<iframe>` + `onLoad/onError` |
| `expo-image` `<Image>` | `<img>` + `onError` |
| RN `Modal animationType="slide"` | HTML5 `<dialog showModal()>` |
| RN `TextInput` | `<input>` / `<textarea>` |
| RN `Pressable` | `<button>` |
| `expo-secure-store` 注入 cookie | `document.cookie = ...` (主域同源) |
| `expo-file-system` 自写 AsyncStorage | `localStorage`（zustand persist 默认） |
