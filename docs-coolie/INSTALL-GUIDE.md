# Coolie App 装机 + 诊断指南 — 2026-09-21

> 最新生产版：**v0.5.2 (502)**。
> 本版自带「装机自检」：装对后 App 首屏会弹出 **Coolie 0.5.2 已就绪** 的说明屏，
> 逐条列出本版功能点，并核对 APK 版本 / OTA 运行时版本。装错（OTA 关着 / 版本对不上）

## 0. 装机前必做（30 秒，专治「装了没变化」）

老板之前装 0.5.0 却看到老界面，根因是**在微信里点链接下载，微信下载管理器缓存/分发了旧 APK**。
装机前先做这三步：

```
1. ❌ 不要在微信对话里点链接下载 APK
2. ✅ 用浏览器「无痕模式」打开下面 §1 的直链
3. ✅ 装之前先卸载旧版 Coolie（设置 → 应用 → Coolie → 卸载）
```

## 1. 装新版 APK

**链接（最新生产 v0.5.2）：**
```
https://dls.xrobinai.cn/coolie/app/0.5.2/coolie-release.apk
```
- 大小：**77,620,770 字节（74.0 MB）**
- 验证：浏览器打开 → 应弹下载；`curl -I` 应返回 `HTTP/1.1 200` 且
  `Last-Modified` 为 2026-09-21。

**装机步骤：**

```
1. 手机「设置 → 安全」开「未知来源」（允许装第三方 APK）
2. 无痕浏览器打开上面链接
3. 下载完成后系统会问是否安装，点「安装」
4. 安装完成后打开 Coolie App
5. 首屏应弹出「Coolie 0.5.2 已就绪」的装机自检屏 → 说明装对了
6. 点「我知道了」进入；App 会自动检查 OTA → 拉到 latest bundle
```

**装完之后重启 App：**

```
任务列表 → 杀后台 Coolie 进程
重新打开 Coolie App
等 ~30 秒（首次启动要初始化 + 检查 OTA + 拉 bundle）
```

## 2. 装完如果「啥也没有」诊断

### 2.1 看装机自检屏（最快判据）

装对 0.5.2 后，首屏会弹「装机自检」：

| 那一行 | 正常 | 异常 |
|---|---|---|
| APK 版本 | v0.5.2 | 别的版本 → 装错 APK |
| OTA 热更新 | 已启用 | **未启用 → 旧 APK，重装** |
| OTA 运行时 | 0.5.2 | 与 APK 不同 → 属正常（bundle 由 OTA 下发），杀后台重开 |

### 2.2 看版本号

```
设置 → 版本号，应该看到: v0.5.2
如果看到 0.3.x / 0.5.0 (304) → 装错 APK，回 §0 重装
```

### 2.3 看「Workspace」入口位置

```
底部 5 Tab: 汇览 / 员工 / 工坊 / 任务 / 本体
↓
点「工坊」(第3个)
↓
进 BoardChatScreen (工坊对话流)
↓
看右上角有 [Workspace] 按钮
↓
点 [Workspace] 弹 Modal
↓ 4 Tab 切换: 对话 / 预览 / 文件 / 终端
```

**如果「工坊」tab 进去是空的（没有对话流）= 没登录 = 看 §3**

### 2.4 看 expo-updates 状态

```
App → 设置 → 版本与更新 (OTA)
应该看到: runtimeVersion = 0.5.2
如果显示别的 = OTA 失败，看 §4
```

## 3. 登录 / 注册

如果 App 装完打开是登录页：

```
1. 注册 / 登录账号（用 weixin 同样的手机号）
2. 进默认公司 / 建公司
3. 进工坊 tab
4. 才能看到 Workspace 按钮
```

## 4. OTA 失败的兜底

如果 §2.4 显示「latest = 没找到」或 stale：

```
方案 A（手动）：
1. 卸载 App
2. 重装 0.5.2 APK（链接同 §1）
3. 第一次打开 App 时确保 WiFi/4G 通
4. 等待 ~30 秒

方案 B（彻底重置）：
1. 卸载 App
2. 清理 Expo Cache（如果用 Expo Go）
3. 重装 0.5.2 APK

方案 C（求助 PM）：
1. weixin 发掌柜 app logcat
2. 掌柜排查
```
