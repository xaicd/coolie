# audit —— 审计日志

**职责：** 记录「谁在何时改了什么」，写读一致、可回放。

## 边界

- **属于本模块：** 变更留痕（actor / 动作 / 目标 / 前后值 / 时间）、审计查询。
- **不属于本模块：** 业务状态机本身；审计只**观察**，不改业务行为。

## 能力

| 能力 | 说明 |
|---|---|
| 留痕 | 对受管辖的变更写审计条目（含 before/after） |
| 查询 | 按公司 / 主体 / 时间 / 动作检索 |
| 回放 | 从审计条目还原一次变更的上下文 |

## 扩展点

- 新增受管辖动作：把该动作接入审计写点；**写点覆盖范围就是审计的可信范围**，要明列。
- 与 `system` 的权限配合：谁能看审计单独授权，不因「是管理员」就默认全开。

## 约束（重要）

- **写进去必须读得出来。** 只写不可读的审计等于没审计 —— 这是缺陷，不是小事。
- 审计条目是**追加**的，不就地改写历史。
