# infra —— 基础设施

**职责：** 文件存储、代码生成、通知、定时任务。

## 边界

- **属于本模块：** 与业务无关的通用基础设施。
- **不属于本模块：** 具体业务文件语义（合同 / 发票 …）、具体业务通知文案。

## 能力

| 能力 | 说明 |
|---|---|
| 文件存储 | 上传 / 下载 / 归档；本地盘或对象存储 |
| 代码生成 | 由模型 / 模板批量生成脚手架代码 |
| 通知 | 站内 / 邮件 / webhook 等通道的投递 |
| 定时任务 | 调度定义与执行记录 |

## 扩展点

- 新增存储后端：实现统一存储接口，不散落直连 SDK 的代码。
- 新增通知通道：注册通道适配器；失败要可观测、可重试。
- 定时任务：幂等优先；执行状态与运行日志必须可读回（写进去读不出来 = 缺陷）。

## 依赖

- 供 `system` / `member` / `audit` 及业务模块使用；本身不依赖业务模块。
