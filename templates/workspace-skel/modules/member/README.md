# member —— 会员体系

**职责：** 会员 / 等级 / 积分（业务侧的客户主体）。

## 边界

- **属于本模块：** 会员主数据、等级规则、积分累积与消耗的通用机制。
- **不属于本模块：** 具体业务权益（商城折扣、CRM 标签 …），那些在对应业务模块里。

## 能力

| 能力 | 说明 |
|---|---|
| 会员 | 会员主体与身份（区别于 `system` 的登录账号） |
| 等级 | 等级规则与升降级 |
| 积分 | 积分账本：发生、结算、查询 |

## 扩展点

- 新的等级规则：作为规则接入评估点，不在各处硬编码阈值。
- 积分变动：走账本式写入（发生记录 + 余额读回一致），禁止直接改一个数字。

## 依赖

- 引用 `system` 的身份；被业务模块（商城 / CRM …）引用。
