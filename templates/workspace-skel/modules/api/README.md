# api —— 对外契约

**职责：** OpenAPI 文档与契约校验。

## 边界

- **属于本模块：** 对外接口的机器可读描述（OpenAPI）、契约与实现的一致性校验。
- **不属于本模块：** 接口的业务实现（属于对应模块）；本模块只描述与校验。

## 能力

| 能力 | 说明 |
|---|---|
| 文档 | 由路由/类型生成 OpenAPI 描述 |
| 校验 | 契约与实现漂移时让构建失败，而不是靠人记住 |

## 扩展点

- 新增接口：一并更新契约描述；**声明与实现不可漂移**（能被检查的约束不该靠人记住）。
- 新版本的接口：显式标注版本与兼容策略。

## 依赖

- 描述 `system` / `infra` / `member` / `audit` 及业务模块暴露的接口。
