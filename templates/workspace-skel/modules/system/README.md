# system —— 组织与访问

**职责：** 用户、角色、权限、菜单、字典。

## 边界

- **属于本模块：** 账号与身份、角色与权限判定、菜单树、数据字典（枚举/码表）。
- **不属于本模块：** 业务规则、业务审批、业务报表（按标书新建业务模块）。

## 能力

| 能力 | 说明 |
|---|---|
| 用户 | 账号、登录身份、状态 |
| 角色 | 角色定义与分配 |
| 权限 | 角色 → 权限点的判定；请求级鉴权 |
| 菜单 | 按角色的菜单树 |
| 字典 | 全局枚举 / 码表 |

## 扩展点

- 新增权限点：在权限目录里声明，配到角色上；判定处统一走鉴权入口，散落判断是坏味道。
- 新增菜单：挂到菜单树；菜单项应对应真实可达的页面，不留死按钮。
- 权限/可见性过滤必须**咬得动**：既要让该看到的看到，也要让不该看到的被拒（双向验证）。

## 依赖

- 被 `audit` 观察（谁做了什么），向 `member` / 业务模块提供身份与鉴权。
