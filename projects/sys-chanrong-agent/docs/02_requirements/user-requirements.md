## 2. 关键业务旅程 (User Journeys)

**旅程 1 · 企业建档与画像穿透**：录入统一社会信用代码 → 自动拉取工商/司法/征信 → 生成企业风险画像标签。
**旅程 2 · 财报核验**：上传财报 → OCR 结构化 → 三表勾稽校验 → 人工确认 → 生成财务分析报告。
**旅程 3 · 授信申请与会签**：提交融资意向 → 智能体测算建议额度 → 超阈值触发双人会签 → 放款。
**旅程 4 · 政策问答**：业务人员提问 → RAG 检索 → 带条款溯源的流式回答。
**旅程 5 · 经营问数**：自然语言问「本月收入/在投规模」→ 安全只读查询 → 指标卡片与趋势图。

## 3. 用户原始诉求 (Voice of Customer)

1. 业务人员无需掌握代码即可完成数据查询与图表生成。
2. 报告编写耗时从数天缩短到分钟级，且结论可溯源、保留人工终审。
3. 风控由被动处置转为主动预警，预警信息精准、分级、不重复、不滞后。
4. 智能体输出必须「事实检索 + 模板填装」，关键数据溯源标注，杜绝幻觉捏造。
5. 移动端零培训即可上手，核心操作两字按钮，实体检视就地浮层。

## 4. 非功能诉求

- 离线私有化部署，数据不出域；多法人实体严格隔离。
- 关键资金/额度动作保留人类复核；操作全程可审计、防篡改。
- 敏感词守卫与内容安全；个人信息加密存储与最小化共享。
