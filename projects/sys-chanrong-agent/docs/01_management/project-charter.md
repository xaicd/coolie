# 产融商业保理与供应链金融智能体系统 项目立项书与范围说明书 (Project Charter)

> **所属业务系统**: 产融商业保理与供应链金融智能体系统 (`SYS_CHANRONG_AGENT`)
> **所属本体域**: `enterprise-core`
> **技术栈**: `node / react / python-vision / docker`
> **存储介质**: `git_repo`
> **规范**: CMMI PLAN / MC（项目策划与监控）
> **编制依据**: 《某公司产融智能体应用系统集成服务项目 技术规范书》

---

## 1. 项目目标与商业价值主张

为甲方（国信产融）在本地化、私有化环境下交付一套覆盖**风险防控、经营管理、知识管理**三大场景的
企业级产融智能体应用系统。商业成败以甲方在真实生产环境中签署《客户终验核销单 (UAT)》为唯一准绳。

## 2. 范围 (In / Out of Scope)

**In Scope**
- 智能体应用平台基础能力（组织/RBAC/菜单/子账户、Agent 编排、模型对接与配额、向量库与文档库、敏感词与知识库）。
- 八大 AI 智能体场景：业务资料核验（财报 OCR）、嵌入式风控、风险预警、尽调报告、投研报告、经营数据分析（ChatBI）。
- 外部集成：甲方门户 SSO、金税发票查验、工商/司法/征信/舆情/行情数据、爱信统一待办。
- 离线私有化部署与硬件指纹 License 授权。

**Out of Scope (Non-Goals)**
- 甲方外围业务系统的改造（由甲方负责统筹与接口改造）。
- 外部数据源的采购与授权（由甲方按需采购，乙方负责技术对接）。
- 移动端以外的第三方渠道深度定制（按合同约定范围）。

## 4. 交付物与验收基线

对齐规范书「项目交付物清单」：SRS、系统功能设计、接口清单、角色权限清单、系统配置文档、
培训材料、测试用例与报告、用户/运维手册、上线计划、初验/终验报告、技术文档（数据库结构/接口）、客制化源码。

**验收节奏**：上线平稳运行 30 天 → 初验；初验后 2 个月 → 终验；终验合格起算 12 个月质保期。

## 5. 关键约束

1. **企业级数据隔离**：多法人实体逻辑隔离，`company_id` 在服务端强制注入。
2. **离线私有化**：推理/检索/OCR 均支持专网脱机运行，不回连公网。
3. **人类复核门禁**：涉及资金、额度批复、放款的状态变更保留人类双人复核。
4. **零假 Demo**：未发生的运行期事实一律留空，禁止伪造业务数据。

## 6. 授权与门禁

本项目采用 CMMI 五大门禁：G1 需求（`verify-reqs`）→ G2 架构（`check-fork-surface`）→ G3 契约（`check-contracts`）
→ G4 验收（`run-tests`）→ G5 投产（`check-release-baseline`）。提交前对应门禁须退出码 0。
本立项书由 `cmmi-asset-authoring` 技能维护，任何范围变更走 CCB 流程。
