# 产融商业保理与供应链金融智能体系统 项目综合管理计划 (Project Plan)

> **所属业务系统**: `SYS_CHANRONG_AGENT`　**本体域**: `enterprise-core`　**规范**: CMMI PP / PMC

---

## 1. 阶段里程碑计划 (Milestones)

| 阶段 | 工作内容 | 目标产物 | 门禁 |
| :--- | :--- | :--- | :--- |
| P0 准备与调研 | 明确范围、三大事业部需求调研（金发/产投/产服） | 立项书、调研纪要 | G0 |
| P1 工程地基与规范基线 | 隔离持久化、统一契约、模块边界、运行时门禁、CMMI 01~09 拓扑 | 本基线 Spec 包 + G1/G2 文档 | G1/G2 |
| P2 一阶段功能 | 企业知识库、业务资料核验（财报 OCR） | SRS/HLD/LLD、可运行模块 | G3 |
| P3 二阶段功能 | 嵌入式风控、风险预警、报告撰写、经营数据分析 | 可运行模块 + 测试报告 | G3/G4 |
| P4 联调与加固 | SSO/待办对接、敏感词与安全护栏、性能调优 | 集成报告 | G4 |
| P5 上线与初验 | 不可变镜像投产、操作手册、30 天试运行 | 部署 SOP、初验报告 | G5 |
| P6 终验 | 稳定运行 2 个月后终验 | 终验报告、UAT 会签 | G5 |

## 2. 工作分解结构 (WBS 一级)

```
W1 项目准备与调研
W2 工程地基（隔离/契约/边界/门禁）         ← 本次交付
W3 智能体应用平台基础能力
W4 风险防控类智能体（核验/嵌入式风控/预警）
W5 经营管理类智能体（报告/经营分析）
W6 系统集成与安全加固
W7 上线投产与验收
```

## 4. 资源与进度约束

- 实施开发期约 9~10 周；试运行 30 天 → 初验 → 稳定 60 天 → 终验。
- 敏捷周迭代，每周五固化可演示原型，关键节点（W4/W6）举行成果展示会。

## 5. 度量与监控 (PMC)

- 需求-用例-契约覆盖率 100%；G1~G5 门禁全绿；编译 0 报错。
- 每周追踪 WBS 完成度与风险状态，偏差 > 20% 触发纠偏。
