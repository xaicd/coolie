# 原型与界面规范: 产融商业保理与供应链金融智能体系统 初始工程地基与规范基线

设计责任人：`emp_fda` / 极简人机产品总监视角
依据：`DESIGN.md`、`.agents/rules/MOBILE-NAVIGATION-STACK-INTEGRITY.md`、公理六「极简主义人机工程」

> 本文件定义地基阶段的两端交互基线：**Web 宽屏承载复杂管理，移动端 6 寸屏收敛为局部一跳因果卡片流**。
> Web 与移动端共用同一套统一 API 契约（见 `design.md §3`），禁止双份业务逻辑。

## 1. 双端信息架构 (IA)

| 端 | 承载 | 首屏 | 核心动作 |
|---|---|---|---|
| PC 控制台 (ruoyi-all-next) | 组织/RBAC、企业档案、发票台账、授信审批台、智能体运营监控 | 经营大盘 | 两字按钮为主 |
| 移动端掌上产融门户 | 局部一跳因果卡片流：待办审批、智能体对话、企业画像、告警 | 待办因果流 | 两字按钮为主 |

## 2. 移动端骨架（公理六硬约束）

- **5 槽位绝对对称底栏**：`[汇览] [任务] [＋] [工坊] [资产]`，消息与审批统一由顶栏 🔔 统领。
- **核心操作按钮 ≤2 汉字**：`【创建】【查看】【审批】【确认】【驳回】【返回】【派单】【发布】`。严禁 >2 汉字或偏心底栏。
- **实体检视就地浮层覆盖 (Inspect In-Place)**：点击任何工单/企业实体，作为全局顶层抽屉就地浮层展示，保持调用方上下文、筛选条件与滚动位置完整无损。
- **先进后出 LIFO 调用栈**：返回处理器严格按渲染层级逆序出栈，根页面执行双击退出保护。
- **两字审批卡片**：高危动作（额度批复、放款、License 越权告警）上提至顶栏 🔔 收件箱，以因果卡片呈现，`【通过】/【驳回】` 就地审批。

## 3. 四态状态机覆盖（每屏强制穷举）

| 页面 | 加载中 Loading | 空数据 Empty | 异常 Error | 就绪 Ready |
| :--- | :--- | :--- | :--- | :--- |
| 企业发票台账 | 骨架屏占位无跳动 | 「暂无发票，请上传」引导 | 离线重试提示 + traceId | 分页表格 + 验真绿标 |
| 智能体对话窗 | 脉冲打字指示器 | 预置 3 个热门问题卡片 | 网络中断重试按钮 | SSE 流式 Markdown 渲染 |
| 授信审批工作台 | 环形进度动画 | 「当前无待办事项」 | 权限不足友好告警页 | 待办工单卡片 |
| 授信申请表单 | 字段骨架 | 未选择企业时的引导 | 校验错误字段级高亮 | 提交/暂存双按钮 |

- **防抖保护**：所有提交、审核、上传按钮强制 `2000ms` 物理防抖与置灰逻辑，根除重复提交。
- **防键盘遮挡**：移动端输入组件统一包裹键盘避让容器。

## 4. Agent-Native 契约（供自动化真机走查）

- Web 元素统一配置 `data-agent-target`。
- 移动端统一配置 `testID=[Screen]__[Component]__[Action]`。
- 弹窗独占配置 `accessibilityViewIsModal` / `inert`。

## 5. 设计令牌红线

所有颜色、间距、圆角、字号一律取自设计令牌层，禁止在组件内写死十六进制、裸 px 或任意 Tailwind 方括号值。
地基阶段不引入任何重复功能入口，坚持「把系统已有能力 100% 用起来」而非新增冗余入口。
