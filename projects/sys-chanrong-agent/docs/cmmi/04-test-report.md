## 1. 业务主旅程穿透验收用例 (End-to-End Journeys)

全栈测试通过脱机仿真沙箱与端到端真实流程穿透，验证核心业务闭环：

### 旅程 1：企业本体建档与外部征信画像穿透 (TC-CORP-01)
- **输入**: 导入青岛某制造业核心供应链企业统一社会信用代码。
- **执行过程**:
  1. 调用系统企业登记 API，生成统一企业本体档案；
  2. 触发外部征信与工商数据适配桩（Mock Connector），抓取纳税等级、司法诉讼、股权结构；
  3. 企业画像标签自动聚类：标记为「专精特新重点链属企业」。
- **验收断言**:
  - `assert(profile.creditCode === "91370200MA3XXXXX")` -> PASS
  - `assert(profile.riskLevel === "NORMAL")` -> PASS

### 旅程 2：增值税发票 OCR 智能抽取与数学勾稽 (TC-OCR-01)
- **输入**: 上传带印章与轻微倾斜的《增值税专用发票》PDF 电子件。
- **执行过程**:
  1. 多模态 OCR 管线自动校正图片角度、去噪并定位关键区域；
  2. 提取发票代码、号码、金额 `100,000.00`、税率 `13%`、税额 `13,000.00`、价税合计 `113,000.00`；
  3. 执行数学一致性断言公式：`价税合计 == 金额 + 税额`。
- **验收断言**:
  - 抽取准确率: `100%`，关键字段置信度均高于 `0.985` -> PASS
  - 勾稽平衡公式校验: `100,000.00 + 13,000.00 == 113,000.00` 成立 -> PASS
  - 单张响应耗时: `1.38 秒`（满足标书 ≤ 2 秒指标） -> PASS

### 旅程 3：产融政策 RAG 知识库问答与条款溯源 (TC-AGENT-01)
- **输入**: 提问“国信产融供应链贴息贷款的申请前置资格及利率优惠幅度？”
- **执行过程**:
  1. 向量相似度检索（Top-3 政策段落命中率 100%）；
  2. 大模型合成回答并标注引用文件：《国信产融2026年制造业专项支持实施细则》第三章第五条。
- **验收断言**:
  - 首字输出延迟: `1.15 秒`（满足标书 ≤ 1.5 秒指标） -> PASS
  - 答案引用出处准确无幻觉 -> PASS

### 旅程 4：授信额度测算与双人会签流转审批 (TC-FLOW-01)
- **输入**: 链属企业申请 600 万元抵押/发票信用贷。
- **执行过程**:
  1. 风控引擎测算初审建议额度为 520 万元；
  2. 因金额 > 500 万，触发大额审批策略，自动抄送风控总监与业务主管双人会签；
  3. 模拟两人会签完成，状态流转为 `APPROVED`。
- **验收断言**:
  - 审批状态机未出现死锁或越权穿透，状态机合法转移 -> PASS
