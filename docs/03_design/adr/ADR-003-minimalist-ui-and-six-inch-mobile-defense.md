# ADR-003: 极简两字 UI 交互契约、黄金对称 5 槽位底栏与 6 寸屏几何防御

- **状态**: 已接受 (Accepted)
- **决策人**: Hermes (PM 掌柜), 门神 (FDSE · menshen-fdse), 百晓生 (DS)
- **决策日期**: 2026-10-05
- **归属规范**: CMMI 03_design (TS) / .agents/skills/adr-architect / .agents/skills/minimalist-ui-and-cmmi-governance

---

## 1. 背景与问题陈述 (Context and Problem Statement)
掌柜与前线 FDE 多数时间在移动端 (6 寸屏手机) 随身看盘与审批。传统企业管理软件动辄多级抽屉、繁冗长句按钮（如“确认提交当前审核并触发异步流转”）、非对称杂乱底栏以及小视口横向撑爆，极大降低决策信噪比。

---

## 2. 考虑的候选方案 (Considered Options)
- **方案 A (采纳)**: **极简两字动作按钮 + 黄金 5 槽位绝对对称底栏 + 就地防遮挡浮层 + 320dp 几何防撑爆**。
- **方案 B**: 传统长文本表单与多级模态弹窗。
- **方案 C**: 仅提供 PC Web 端，移动端通过浏览器缩放查看。

---

## 3. 决策结果 (Decision Outcome)
**选用方案 A**。
- **两字按钮契约**: 核心操作按钮文案长度严格限制为 $\le 2$ 个汉字（【派活】、【通过】、【驳回】、【签出】、【释放】、【提额】）；
- **对称底栏**: Expo 移动端与 Web 端底栏统一保持黄金 5 槽位绝对对称，单手拇指热区可达；
- **小屏防御**: 在 320dp 至 430dp 视口下实施零横向滚动条防御，模态浮层就地居中或全屏覆盖，严禁遮挡底部核心导航栏；
- **门禁守卫**: 纳入 Pre-commit Gate 16.2 自动化扫描与 Gate 24 真实模拟器截屏走查。
