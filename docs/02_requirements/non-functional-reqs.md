# 非功能性需求与性能指标规范 (Non-Functional Requirements - NFR)

- **制定日期**: 2026-10-17
- **归属规范**: CMMI 02_requirements (RDM) / .agents/skills/cmmi-req-spec

---

## 1. 性能与容量约束
- 单机独立进程吞吐量容量护栏: >= 5,000 RPS
- API P95 响应延迟: <= 50ms
- 错误预算: 核心交易链路 99.95% 可用性

## 2. 安全合规与数据保护
- 租户隔离: 严格按企业域隔离，杜绝越权
- 敏感数据: 密码高熵哈希存储、手机/证件自动脱敏
