## 1. 系统容量与性能指标 (Performance & Scalability)

| 指标维度 | 评估场景 | 生产指标门禁 (Threshold) | 监控与度量方式 |
| :--- | :--- | :--- | :--- |
| **API 响应延迟 (P95)** | 控制面核心接口 (`/api/companies`, `/api/issues`) | $\le 50\text{ ms}$ (读请求)<br>$\le 150\text{ ms}$ (写事务) | Prometheus / OpenTelemetry 链路监控 |
| **高频吞吐能力 (TPS/QPS)** | 网关接入层并发压力测试 | $\ge 2,000\text{ QPS}$ (单实例基准) | k6 / wrk 压测基准套件 |
| **本体反射审计耗时** | 全量 263 表 AST 双向反射校验 | $\le 3.0\text{ 秒}$ | `scripts/harness-ontology-audit.mjs` 实测耗时 |
| **本地开发启动耗时** | 纯 PGlite 嵌入式环境冷启动 | $\le 5.0\text{ 秒}$ | `pnpm dev` 自动化探针 |
| **移动端首屏加载时间** | Expo SDK 52 原生应用冷启动 | $\le 1.8\text{ 秒}$ | Android 模拟器真机性能走查 |

## 2. 系统可靠性与可用性 (Reliability & Availability)

1. **服务可用性 (SLA)**: 生产控制面月度服务可用性 $\ge 99.95\%$（允许月度不可用时间 $\le 21.6$ 分钟）；
2. **零死穴异常防御**: 所有异步调用与网络通信强制使用 `try/catch` 结构兜底，严禁未捕获的 Unhandled Rejection 导致 Node 进程崩溃；
3. **断网与宕机自愈**: Hermes 智能体心跳超过 60 秒无响应自动触发状态熔断与接力机制，保证交付流水线不中断。

---

## 3. 安全性与等保三级基线 (Security & Compliance)

1. **凭证脱敏与哈希存储**: 智能体 API Key 与外部系统密码严禁明文入库，必须使用 SHA-256 加盐哈希或高强度加密算法存储；
2. **零弱口令铁律**: 生产环境与测试环境严禁包含 `admin123`、`123456` 等高熵不足的弱密码（Pre-Commit Gate 18 强制扫描）；
3. **防注入与参数化查询**: 所有数据库访问统一经由 Drizzle ORM 参数化编译，严格禁止字符串拼接 SQL，杜绝 SQL 注入漏洞；
4. **多租户行级数据隔离**: 组织与公司数据边界强制在 ORM 查询层与服务层双重校验，杜绝水平越权漏洞。

---

## 4. 人机交互与可访问性设计约束 (Usability & Viewport Defense)

1. **6 寸屏小视口防御 (320dp~430dp)**: 页面所有容器宽度必须采用自适应流式布局，严禁出现固定大像素导致水平横向溢出滚动条；
2. **两字动词法则**: 界面核心操作按钮必须收敛至两个汉字以内，减少掌柜决策认知负荷；
3. **底栏 5 槽位绝对对称**: 原生移动端底栏固定为 5 个核心入口，图标与文字严格居中对称对齐。
