## 一、 顶层架构愿景与生态隐喻 (Foundry Vision & Metaphor)

传统软件研发流程中，工具链高度碎片化（Jira、GitLab、Swagger、Wiki、Jenkins、Postman、Grafana 各自为政），导致“需求漂移、代码腐化、人肉评审滞后、文档与代码脱节、大模型开发并发踩踏”。

## 二、 改造核心四大基石 (The 4 Pillars of Transformation)

### 1. 通用化 CLI 引擎改造：`coolie-dev` 独立安装与全局执行
- **痛点**: 当前 `coolie:dev` 紧耦合于当前仓库路径 (`REPO_ROOT`) 与 Mac 宿主机的特定环境。
- **改造目标**:
  - 打包为全局可执行 CLI（`npm install -g coolie-dev` 或二进制独立分发）；
  - 提供单命令一键部署：`curl -fsSL https://get.coolie.ai | bash`；
  - 自动探测多机物理拓扑（Mac, cwall, aja-pc, tc-coolie-claw）与容器沙盒，智能自愈。

### 2. 任意项目物理接管流水线 (`coolie-dev takeover`)
在任何项目根目录下执行 `coolie-dev takeover`，触发四阶自闭环流水线：
1. **工程基座自省 (Inspection)**:
   - 嗅探语言与框架（Spring Boot / Vue / Expo / Next.js / FastAPI / Django 等）；
   - 嗅探持久化层（PostgreSQL / MySQL / Oracle / SQLite / Prisma / Drizzle / MyBatis）；
   - 嗅探 API 契约与路由定义；
   - 嗅探 Git 状态与分支健康度。
2. **控制面建档与本体绑定 (Project as Domain)**:
   - 调用控制面 API 原子创建对应的 `Project` 与专属 `Ontology Domain`；
   - 映射本地工作区路径至控制面工作区总线 (`metadata.resourceRef`)。
3. **动态设计与需求资产逆向合成 (Reverse Doc Synthesis)**:
   - 驱动 `cmmi-doc-generator.cjs`，从被接管项目的代码物理内省：
     - 生成 `software-requirements.md` (SRS) & `requirements-traceability-matrix.md` (RTM)；
     - 生成 `database-design-erd.md` (数据库物理表与 Mermaid ERD)；
     - 生成 `interface-contracts.md` (统一 REST/OpenAPI 接口契约)；
     - 生成 `ui-design-prototype-spec.md` (UI 页面路由与 6 寸屏防御)；
     - 生成 `architecture-design-hld.md` (系统总体架构概要设计)；
     - 生成 `low-level-design.md` (详细设计与核心服务流转)。
4. **主线常驻例行任务注入 (Routine Keeper)**:
   - 自动在控制面为该项目注册常驻保活巡检任务，保持小时级心跳，永不冷寂停滞。

## 三、 Hermes 作为认知芯片的工程化落地方案

将 Hermes 的“芯片”概念物理化为 4 个硬件级单元模块：

1. **指令流水线与意图解码核 (Intent ALU)**:
   - 监听来源：Web 控制台、移动端 Cockpit、微信多模态感知通道 (`hermes-wechat-monitor`)；
   - 指令转译：将口语句式快速标准化为 EARS 需求语法，并映射至系统活体本体的 `ActionType`；
2. **算力总线仲裁器 (Dispatch Bus Arbiter)**:
   - 根据任务类型（架构设计、复杂重构、页面走查、配置修改），动态选择 7 工具池最省 Token 且推理能力最强的智能体；
3. **原子互斥锁与时钟管理器 (Mutex & Clock Manager)**:
   - 托管 `executionLockedAt` 与 `lockedBy`，管理 15 分钟租约与心跳保活；
   - 杜绝多员工并发写入同一个代码分支；
4. **中断与硬熔断保护单元 (Interrupt & Circuit Breaker Unit)**:
   - 每次 Tool Call 实时计费累加；
   - 预算耗尽时发出致命中断 (`INT_BUDGET_STOP`)，冻结执行并向掌柜手机推送两字【审批】卡片。

## 四、 实施计划与里程碑 (Roadmap)

- **M1 (当前已完成)**:
  - 落地 `scripts/cmmi-doc-generator.cjs`，实现物理代码内省与 6 大核心设计/需求文档批量模版动态替换生成；
  - 验证通过 `pnpm cmmi:check`、`pnpm cmmi:reverse-audit` 与 25 道物理预提交门禁。
- **M2 (优化改造阶段)**:
  - 增强 `scripts/coolie-local-dev.sh` 与脚手架体系，提供 `coolie-dev takeover` 与 `coolie-dev fleet setup` CLI 命令；
  - 支持在任意外部工作区（`--dir <path>`）自动建立工程上下文、注入 6 大数字员工花名册、并逆向生成 CMMI 01~09 规范产物；
  - 强化 Hermes 芯片中枢指令，建立标准意图进厂与 7 工具池自适应桥接。
- **M3 (全局交付阶段)**:
  - 将 `coolie-dev` 打包为独立分发的 CLI 包与 Docker 容器沙盒；
  - 实现任何新项目“一条命令装机 ➔ 10 秒数字员工就位 ➔ 全生命周期完全接管”。
