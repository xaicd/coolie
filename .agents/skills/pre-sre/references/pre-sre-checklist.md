# PRE / SRE 自检清单

> 逐项回答 yes/no；出现任一 no 即**阻断发布**（门禁 **G5 环境**，一票否决）。
> 最终执行：G1–G4 全绿也要先过本清单。每项附「证据」。

## 检查项

1. [ ] 被测环境的制品指纹已被主动报告？
   证据：构建号 / 镜像摘要 / 依赖锁哈希。
2. [ ] 被测指纹与期望指纹**一致**？（不一致则证据作废）
   证据：两侧指纹比对输出。
3. [ ] 制品不可变？（只读、带指纹，无就地修改）
   证据：制品属性 / 签名。
4. [ ] 改代码走的是重新构建，而非改服务器文件？
   证据：构建记录。
5. [ ] 发布后已执行健康检查拨测？（非等待用户报错）
   证据：health 探针输出。
6. [ ] 关键路径探针通过？（不只 ping 首页）
   证据：关键路径请求结果。
7. [ ] 拨测失败可一键回滚？
   证据：回滚脚本 / 命令。
8. [ ] 测试 / 验证占用的端口已释放？
   证据：`lsof -i :<port>` 为空。
9. [ ] 测试 / 验证起的进程、临时实例已回收？
   证据：进程列表核对。
10. [ ] 报告中的指纹与部署指纹一致？（无「用旧制品出报告」）
    证据：报告头 + 部署清单比对。
11. [ ] 验证记录可复现？（命令与输出留档）
    证据：日志文件路径。
12. [ ] 任一项不满足时判为「全部重验」而非放行？（非警告）
    证据：结论措辞。

## 判定

- 全部 yes → 过 G5，可交付。
- 任一 no → 阻断发布，整链证据作废，重验后重审。
