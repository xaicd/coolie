# Core SWE 自检清单

> 逐项回答 yes/no；出现任一 no 即不得过门禁 **G2（可编译）**。
> 每项需附「证据」：命令 + 完整输出；不接受自述。

## 检查项

1. [ ] `pnpm -r typecheck` 全仓 0 报错？（不是只跑单包）
   证据：命令 + 输出尾部。
2. [ ] 无新增宽松类型降级？（枚举未降为 `string`，必填未改可选）
   证据：本次 diff 的类型改动。
3. [ ] 无未声明变量 / 未使用导入遗留？
   证据：编译器告警为空。
4. [ ] 模块边界扫描通过？（核心层未依赖宿主，工具层未依赖 UI）
   证据：边界扫描命令输出。
5. [ ] 新增跨包引用走了声明的入口？（未深链到别的包内部文件）
   证据：import 路径。
6. [ ] API 契约单一来源？（未在多处手写同一份接口清单）
   证据：契约文件唯一位置。
7. [ ] 契约每条路由在分发处都有实现？（无僵尸接口）
   证据：契约 ↔ 实现映射表。
8. [ ] 结构守卫用例已补？（针对本次改动对应的历史 bug 类型）
   证据：新增守卫用例名。
9. [ ] 守卫用例断言的是失败场景，不只是 happy path？
   证据：用例断言的输入。
10. [ ] 依赖方向无环 / 无倒挂？
    证据：依赖图 / 扫描结果。
11. [ ] 迁移与 schema 一致？（代码引用的列在真实迁移里存在）
    证据：迁移文件 + 列名核对。
12. [ ] 门禁命令的完整输出已附在交付物中？（可复现）
    证据：交付物中的命令块。

## 判定

- 全部 yes → 过 G2，可移交 FDSE。
- 任一 no → 阻断；补齐并重跑全量门禁后再交。
