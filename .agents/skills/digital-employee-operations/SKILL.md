# Hermes 数字员工端到端业务接管与自治运营工作流 (Digital Employee Operations)

本 Skill 确立了乡村振兴综合服务平台的**战略级运营范式**：

> **核心宪法**：**E2E 不仅仅是软件测试的被动断言工具，更是由 Hermes 智能体直接驱动的“数字员工（Digital Employees）”核心业务执行手臂！**
>
> 平台后续的产品设计、UI设计、研发编码、质量测试、持续部署以及**全流程商业化运营（Merchant Operations & Governance）**，全部交由具备自主行动能力的 Hermes 数字员工接管。

## 一、从“传统自动化测试”到“数字员工自治运营”的质变

| 维度 | 传统 E2E 测试 | Hermes 数字员工自治运营 |
| :--- | :--- | :--- |
| **执行目标** | 断言某个 DOM 元素在不在、接口返不返回 200 | **全生命周期业务交付与运营自愈**：让真实商铺、地块、客房、课程拥有生产级高品质数据与交付闭环 |
| **造数方式** | 原始 SQL/Prisma 写入空值或模拟 mock 字符 | **业务拟真行为**：模拟真实商户端操作，上传 HD 高清摄影、课件、视频，配置合理售价与履约选项 |
| **异常处理** | 测试用例红灯退出并打印堆栈 | **自主修复巡检**：若发现地块无图片、商品无 SKU、店铺无门面，数字员工立即调取资源池补齐修复 |
| **业务闭环** | 只跑单点链路，往往留下孤立数据与死穴跳转 | **多端全景穿透**：商户上架 → 超管审核 → C 端 App/Web 渲染展示 → 用户下单签约 → 履约核销 |

## 三、四大业态数字员工标准化执行规程 (SOP)

### 1. 共享菜园与农旅地块运营 (Farm Operations)
- **地块基础信息**：严格定义地块编号（`A-001` 等）、面积（20~100㎡）、朝向（`SOUTH`/`EAST` 等）、土壤类型（`LOAM`/`CLAY`）与酸碱度（`pH 6.5~7.2`）。
- **实景多媒体要求**：
  - **缩略图与画廊**：必须配置经过验证的高清农田、有机菜畦、温室大棚实景摄影（来自已验证的高清池，分辨率 $\ge 1200\text{px}$）；
  - **全景 VR 导览**：必须配置 360 度全景地块图片，支持 C 端全景漫游；
  - **IoT 设施标注**：明确标注监控摄像头（Camera Stream）、智能土壤水肥传感器（Sensor）与喷灌设备（Irrigation）。
- **销售绑定强契约**：
  - 严禁地块裸售！地块必须通过 `productSkuFarmPlotBinding` 绑定在售商品与 SKU，明确月付/季付/年卡套餐金额；
  - C 端展示必须显示真实的起步价格（如 `¥368 套餐起`），严禁“暂未定价”。

### 2. 精品民宿与特色客房运营 (Homestay Operations)
- **客房规格**：房型名称、可住人数、床型配置（大床 1.8m / 双床 1.2m）、卫浴设施、网络空调全量标注。
- **视觉图集**：至少 3 张高清实拍（客房全景、床品细节、窗外山景/院落）。
- **房态与阶梯定价**：绑定周中/周末/节假日房价日历，设置不可退/免费取消政策。

### 3. 乡村特产与非遗电商运营 (Specialty Commerce Operations)
- **商品档案**：商品正名（禁止“测试”字样）、规格明细（如 2.5kg 礼盒装、一级头采）。
- **包装与实物图**：展示田间采摘、包装礼盒、产品剖面高清图。
- **物流履约**：顺丰/冷链直配配置，到货时间说明。

### 4. 研学教育与职业农人培训 (Education & Training Operations)
- **遵循 `course-commerce-generation` 标准**：
  - 真实教师档案（高级农艺师、非遗传承人）；
  - 标准 Office Open XML 演示文稿（`.pptx`）；
  - 矢量排版 PDF 实训讲义（`.pdf`）；
  - H.264/AAC 编码高清实训视频（`.mp4`）；
  - 包含章节时长与随堂练习题。

## 四、数字员工自治巡检与自愈三原则

1. **零空白占位原则 (Zero Blank Placeholders)**：
   - 前端页面严禁直接暴露单调灰底矢量图标（如 `<Sprout />` 或空占位）；
   - 代码层必须实施“数据缩略图 → 图集第一张 → 业务类型确定性高清图池”三级防御兜底；
   - 数字员工在巡检时，若检测到 `img` 缺失或 404，必须立即启动资产补齐流水线。
2. **零死穴链接原则 (Zero Dead Links)**：
   - 首页所有推荐卡片、分类金刚区、地块列表行，点击后必须能 100% 成功下钻到详情页；
   - 详情页必须具备明确的操作主行动点（立即预订 / 立即认养 / 立即购买）。
3. **真实资金闭环原则 (True Cashier Journey)**：
   - 订单生成后必须能够拉起统一下单与收银台（Cashier）；
   - 支持扫码模拟支付、退款全流程闭环对账。

## 五、数字员工工具箱与常用操作命令

| 命令 | 职责 |
| :--- | :--- |
| `npm run digital-employee:farm` | 启动共享菜园数字运营官：巡检并补齐地块高清实景、认养套餐，执行移动端 C 端视觉验收 |
| `python3 scripts/multimedia/generate-course-assets.py` | 启动教育数字员工：自动生成符合教学规范的 PPTX、PDF 讲义与 MP4 实训视频 |
| `npm run test:e2e:course-materials` | 启动教育商户数字员工：自动化登录商户后台、建立讲师档案、发布多章节多媒体课程 |
| `npm run db:seed:test-env-quality-upgrade` | 启动全域数字员工数据升级基线：覆盖全组织、全用户、全分类、全业态商户的高质量演示资产治理 |
| `bash scripts/security/strix-scan.sh ./ quick 10` | **安全测试技能**（`strix` 技能，非新角色）：对自有代码/接口跑渗透测试，由现有数字员工/编码 agent 调用（本地 CLI，禁云；仅授权目标）|
