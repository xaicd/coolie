# FDA 自检清单

> 逐项回答 yes/no；出现任一 no 即不得过门禁 **G1（设计）**。
> 每项需附「证据」：命令输出 / 代码行号 / 表；不接受口头承诺。

## 检查项

1. [ ] 每个领域实体的租户归属已写明？
   证据：实体 → 租户键（companyId）映射表。
2. [ ] 隔离强制点在**服务端**？（非客户端 / UI 层）
   证据：中间件或服务层文件:行号。
3. [ ] 存在至少一条跨租户访问被拒的用例？
   证据：可复现请求 + 实际返回码（403 / 404）。
4. [ ] 客户端传入的租户标识被服务端覆盖或校验？
   证据：入参覆盖 / 校验代码行。
5. [ ] 新增实体已归入某个域？（无「无主实体」）
   证据：领域归属说明。
6. [ ] 越域访问有明确拒绝路径？
   证据：403 与 404 的选择理由。
7. [ ] 权限矩阵覆盖读 / 写 / 批三列？（无遗漏操作）
   证据：操作 × 角色表。
8. [ ] 提案与批准已分离？（无自批自审）
   证据：角色 / 权限配置片段。
9. [ ] 资金 / 库存操作有原子事务边界？（含失败回滚）
   证据：事务包裹代码行。
10. [ ] 守恒断言已写进事务？（双向对账 + 防重复冲销）
    证据：断言语句位置。
11. [ ] 隔离 / 权限 / 守恒的强制点能指到具体文件行？（非「约定」）
    证据：路径:行号清单。
12. [ ] 边界文档与实现一致？（无「文档写了代码没做」）
    证据：文档 ↔ 代码 diff 核对。

## 判定

- 全部 yes → 过 G1，可移交 Core SWE / FDSE 实现。
- 任一 no → 阻断，补齐后重审；不得以「后续补」放行。
