# 术语纠错表

只收录**在本课程语料中反复出现**的错误（高考志愿填报 / 本科专业解读类）。
不在此表的同音错字，按上下文判断；判断不了就标 `【?】`，不要猜。

## 一、人名

ASR 对「张雪峰」的识别极不稳定，同一集内会混用多种写法，**必须统一为「张雪峰」**。

| 易错写法 | 正确 |
|---|---|
| 张雪芳、张雪峰、张雪锋、张老师 | 张雪峰 / 张老师（同段落内统一） |

## 二、固定表述

讲者每讲开头的自我介绍是 ASR 重灾区，几乎每讲错法都不同，全部还原为同一句：

> **我是让学习变得更快乐的张雪峰老师**

| 易错写法（实测样本） | 正确 |
|---|---|
| 我上学期变得更快乐的… | 我是让学习变得更快乐的… |
| 我上学习编的,跟我回来的… | 我是让学习变得更快乐的… |
| 我是上午学习编的更回来的… | 我是让学习变得更快乐的… |
| 我上次学习别的更快乐的… | 我是让学习变得更快乐的… |
| 本科证研田报、本科证院填报 | 本科志愿填报 |
| 志愿田报、自愿填报 | 志愿填报 |
| 自愿（指报考时） | 志愿 |
| 节节课 | 这节课 |
| 本科专业目录、本科专业 | 本科专业目录 |
| 报志愿、填报志愿 | 报志愿 / 填报志愿 |

## 六、转写模型的幻觉尾句（直接删）

语音转写模型在片尾静音段会**编出**一段它训练语料里常见的结束语。这不是讲者说的话，
是模型的产物，**必须整句删除**——留着会污染讲义，也会让教案凭空多出一条不存在的行动建议。

实测样本（中文课程语料）：

| 幻觉原文 | 说明 |
|---|---|
| 请不吝点赞 订阅 转发 打赏支持明镜与点点栏目 | YouTube 风格的固定尾句，与课程无关 |
| 字幕由 XXX 字幕组提供 | 同上 |
| 感谢观看，我们下期再见（在讲者没说的情况下） | 需判断：讲者本人常说的结束语保留，模型补的删 |

**判定方法**：这句话是否与课程内容无关、且句式高度模板化？是 → 删。
**不确定时**：看它前面是否已经有讲者自己的收尾语（「咱们下节课再见，谢谢」）。
已经有收尾语之后的模板句，基本都是幻觉。

---

## 七、判断规则

1. **先查表，再判上下文。** 表里有的一律按表改。
2. **同一名字全篇统一。** 若一集里既出现「张雪峰」又出现「张雪芳」，统一成出现次数更多、
   且与公开事实一致的那个（张雪峰）。
3. **专业名改动要保守。** 把「医学影像学」误改成别的专业名，比留着错字危害更大。
   拿不准就在该处标 `【?】`。
4. **数字一个都不能改。** 分数、比例、排名、年份即使看起来可疑也照抄；
   若与上下文明显矛盾，照抄并在句后加 `【? 原文如此】`。
