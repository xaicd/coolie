# BOOTSTRAP.md — 首次引导

欢迎使用 Coolie 智能体工坊!

## 快速开始

1. **编辑 SOUL.md** — 定义你的智能体人格和行为风格
2. **编辑 USER.md** — 告诉智能体你的技术栈和偏好
3. **编辑 HEARTBEAT.md** — 设置需要定期检查的事项 (可选)
4. **删除此文件** — 完成引导后删除 BOOTSTRAP.md, 智能体将进入正常工作模式

## 文件说明

| 文件 | 用途 |
|------|------|
| `SOUL.md` | 智能体人格定义 |
| `USER.md` | 用户画像与偏好 |
| `IDENTITY.md` | 智能体身份信息 |
| `AGENTS.md` | 工作区行为规范 |
| `TOOLS.md` | 本地环境备注 |
| `HEARTBEAT.md` | 心跳检查清单 |
| `MEMORY.md` | 长期记忆摘要 (自动生成) |
| `memory/` | 每日结构化记忆日志 (自动生成) |
| `skills/` | 用户级技能目录 |
