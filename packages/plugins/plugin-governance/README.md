# @paperclipai/plugin-governance

企业级架构与质量治理插件 (Enterprise Architecture & Quality Governance Plugin).

## 核心功能
1. **CMMI 5+2 质量门禁与基线**: G1 (需求) ~ G5 (投产) 质量门禁会签，5 核心 + 2 扩展黄金文档基线管理，RTM 双向需求跟踪穿透，SPC 3σ 过程控制图与 5-Why 鱼骨溯源。
2. **微服务活态三态拓扑 (Living Topology)**: SkyWalking 分布式链路追踪集成，ChaosBlade 混沌工程注入实验与自愈演练。
3. **DSH API 全生命周期契约治理中心**: HTTP / gRPC / Dubbo / MQ 多协议契约统一治理，自动导出 MCP Tool，实时沙箱联调与代码桩生成。
